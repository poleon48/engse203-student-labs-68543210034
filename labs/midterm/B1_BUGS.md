## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

| อาการ | ไฟล์ : บรรทัด | สาเหตุ | แก้อย่างไร |
|---|---|---|---|
| กดปุ่มไม่ได้ แต่พอโหลดหน้าเสร็จฟังก์ชันทำงานเองทันที | `Foo.jsx : 12` | เขียน `onClick={handleClick()}` มีวงเล็บ → JavaScript **เรียกฟังก์ชันทันที**ตอน render แล้วเอาค่าที่ return มาเป็น handler | เอาวงเล็บออก เป็น `onClick={handleClick}` (ส่งตัวฟังก์ชัน ไม่ใช่ผลลัพธ์) |

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป | `SummaryPanel.jsx` | การเรนเดอร์ไอเทมในลูปขาดการกำหนด prop `key` ทำให้ React ไม่สามารถระบุตัวตนของแต่ละเรคคอร์ดได้ | เพิ่ม prop `key={item.id}` เข้าไปในองค์ประกอบหลักที่ถูกวนลูป |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `DashboardPage.jsx` | เขียนเงื่อนไขหรือฟังก์ชันนับสเตตัสใน summary ผิดพลาด ไม่ตรงกับค่าสถานะจริงในระบบ | แก้เงื่อนไขตัวกรองใน `summary` ให้เช็คสถานะ `'completed'` ให้ถูกต้องตรงกับฐานข้อมูล |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน (เหมือนกรองไม่ทำงาน) | `DashboardPage.jsx` | โค้ดกรองข้อมูลถูกฮาร์ดโค้ดค่าสเตตัสไว้ตายตัว ไม่ได้อ้างอิงตามค่าที่ผู้ใช้กดเลือกจริง | เปลี่ยนจากค่าตายตัวให้มารับค่าผ่านตัวแปร `statusFilter` ที่ผู้ใช้กดเลือก |
| 4 | เปลี่ยน URL `REQ-101` → `REQ-102` แล้วข้อมูลไม่เปลี่ยน | `RequestDetailPage.jsx` | ใน `useEffect` มีการดึงข้อมูลตาม ID แต่ลืมใส่ตัวแปร ID ไว้ใน Dependency Array ทำให้อีเฟกต์ทำงานแค่ตอนเปิดหน้าครั้งแรก | เพิ่มตัวแปร `requestId` ลงไปในวงเล็บ dependency array `[requestId]` เพื่อให้ดึงข้อมูลใหม่ทุกครั้งที่ URL เปลี่ยน |
| 5 | กด "ลบ" แล้วการ์ดหาย แต่ตัวเลขในแผงสรุปไม่ลด | `DashboardPage.jsx` | ฟังก์ชันลบข้อมูลเป็นแบบ Async แต่ลืมใส่ `await` ทำให้ตัวแปรที่เก็บผลลัพธ์กลายเป็น Promise เปล่า ๆ ไม่ใช่ Array ข้อมูล | เติมคำว่า `await` หน้าฟังก์ชันลบ เพื่อรอให้ข้อมูลอัปเดตกลับมาเป็น Array จริง ๆ ก่อนเซ็ตค่า State |
| 6 | กด "ลบ" แล้วหน้าพัง/ว่างเปล่า | `DashboardPage.jsx` | ต่อเนื่องจากข้อ 5 พอค่าที่ได้ไม่ใช่ Array แต่เป็น Promise ตัวฟังก์ชัน `.filter()` จึงพังและพ่น Error ออกมา | แก้ไขด้วยการใส่ `await` ในฟังก์ชันลบข้อมูล ให้ส่งค่าคืนกลับมาเป็น Array ที่ถูกต้อง เพื่อให้คำสั่ง `.filter()` ทำงานต่อได้ปกติ |
